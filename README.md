# Financial Intel

Osobista aplikacja budżetowa na Windows (Electron): finanse jako systemy okrętu, analizy w języku ICT. Siostrzana
aplikacja ICT Trade Journal (`Clatir/TradingJournal`).

- Specyfikacja: `docs/specyfikacja.md`, decyzje: `docs/decyzje.md`, plan: `docs/plan.md`, postęp: `docs/postep.md`.
- Pobranie: [GitHub Releases](https://github.com/Clatir/FinancialIntel/releases) – `Financial-Intel-Setup.exe`
  (instalator) albo `Financial-Intel-portable.exe`.
- Budowanie: `npm ci`, `npm test`, `npm run build`; na Windows bez wymagań co do Node: `build-windows.cmd`.
